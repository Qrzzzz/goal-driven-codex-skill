# Contributing

Thanks for improving this project. Keep contributions small, bounded, and easy to review.

## Guidelines

- Open an issue for suggestions before large changes.
- Keep the project focused on controlled goal-driven Codex workflows.
- Avoid adding infinite-loop behavior.
- Preserve explicit validation commands and stop conditions.
- Keep English and Chinese README content aligned.

## Pull requests

Before opening a pull request:

- Check that Markdown links are valid.
- Keep examples practical and scoped.
- Do not add generated binary images unless they are intentionally produced and reviewed.
- Confirm that `skill/agents/openai.yaml` keeps implicit invocation disabled.
