# Assets

This directory stores generated visual assets used by the README files.

Expected generated files:

- `overview-en.png` for `README.md`
- `overview-zh-CN.png` for `README.zh-CN.md`

The prompt files are included for reproducibility:

- `overview-en.prompt.md`
- `overview-zh-CN.prompt.md`

Do not commit generated binary image files unless they are intentionally produced and reviewed for release.
